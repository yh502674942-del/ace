## 运行

推荐在项目目录启动本地静态服务器：

```bash
python3 -m http.server 4181 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4181/index.html` 游玩。直接打开 `index.html` 也可用于普通浏览器，但 Codex 内置 Browser 可能会拦截 `file://` 页面，因此本地服务器方式更稳定。
